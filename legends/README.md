## 这是什么

金铲铲之战「英雄联盟传奇」赛季下的**海克斯典籍**玩法攻略，与站内现有的 S18「自然之力」是**两套不同内容**：

- 现有 `/guides`、`/comp` 等 → S18 自然之力
- 本板块 `/legends` → 英雄联盟传奇 · 海克斯典籍（核心是**城邦钥匙**机制）

## 目录结构

```
legends/                    ← 板块独立目录（内容与样式都在这里，不混进主站其他内容）
├── README.md               ← 本文件
├── legends.css             ← 板块样式（作用域限定 .lg，不污染主站）
└── data/
    ├── keys.js             ← 城邦钥匙全览（秩序 / 科技）
    ├── comps.js            ← 阵容攻略
    └── items.js            ← 装备攻略

app/legends/                ← 站点路由（新窗口）
├── layout.js               ← 板块布局（引入样式 + 子导航）
├── LegendsNav.js           ← 子导航（客户端组件）
├── page.js                 ← 总览（强度向 + 整活向分组入口）
├── keys/page.js            ← 城邦钥匙全览
├── comps/page.js           ← 阵容列表（按玩法类型分组，30 套）
├── comps/[slug]/page.js    ← 阵容详情页（每篇独立 URL，利于 SEO）
└── items/page.js           ← 装备攻略
```

主站导航已加入入口：`components/SiteNav.js` → `{ href: '/legends', label: '海克斯典籍' }`
Sitemap 已纳入：`app/sitemap.js` → `/legends` 四页 + 30 个 `/legends/comps/<slug>`，priority 0.85-0.9。

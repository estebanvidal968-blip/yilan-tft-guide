# 弈览 · SEO 主动推送与抢词发布 SOP

**目的**：把「等百度爬虫慢慢爬 sitemap」换成「发布即主动推送」，收录从**天级 → 分钟级**，内容资产复利获客、零成本。

---

## 1. 为什么主动推送更快

| 方式 | 收录速度 | 说明 |
|---|---|---|
| 仅提交 sitemap.xml | 天级（爬虫排期） | 百度按权重排爬取计划，新站慢 |
| **主动推送 API（本脚本）** | 分钟级 | 你主动把 URL 推给搜索引擎，优先抓取 |

搜索引擎对「主动推送」的 URL 赋予更高抓取优先级，尤其对新站/新内容效果明显。

---

## 2. 获取凭证（一次性）

**百度（必做）**
1. 登录 [百度资源平台](https://ziyuan.baidu.com) → 站点管理 → 验证并选中 `yilangames.com`。
2. 左侧「数据推送」→「主动推送」→ 复制 **token**（一长串字符）。
3. 记下每日「剩余可推送条数」配额（新站通常几百~几千）。

**必应 / Bing（必做，覆盖全球 + 国内部分）**
1. 登录 [Bing Webmaster Tools](https://www.bing.com/webmaster) → 添加并验证站点。
2. 设置 → API 访问 → 生成 **API key**。

> 注：360 / 搜狗国内份额小，暂不强求；后续可补。

---

## 3. 运行

```bash
# 设置凭证（仅本次会话生效，勿写进仓库）
export BAIDU_PUSH_TOKEN="你的百度token"
export BING_API_KEY="你的必应key"

# 默认：只推首页 + 28 篇攻略（优先集，省配额，推荐日常用）
npm run seo:push

# 全量：推 sitemap 全部 URL（配额充足或重大更新时用）
npm run seo:push -- --all
```

未设置 token/key 时脚本**自动跳过**对应平台，只做 sitemap 抓取与解析校验（可当健康检查用）。

返回示例：`[baidu] 推送 29 条 -> {"success":29,"remain":971,"not_valid":[]}`

---

## 4. 接部署流程（关键：发布即推送）

每次 `deploy` 上线后，紧接着跑一次推送。两种接法：

- **本地手动（推荐，token 留本地不外泄）**：deploy 命令跑完 → `npm run seo:push`。
- **服务器定时**：在服务器 crontab 加每日 `curl sitemap + 推送`（需把 token 放到服务器 env，有泄露风险，慎选）。

当前 deploy 脚本（`deploy/deploy-20260907.sh`）不含推送步骤，由本地发布后手动触发。

## 5. 抢词发布 SOP（版本更新当天 = 白捡搜索量）

金铲铲每个版本/热修补丁，搜索词「S18 最强阵容 / 金铲铲攻略」会瞬间放量。卡准节奏：

1. **T-0（版本上线当天）**：第一时间在站上发 1–2 篇新版本攻略（阵容码 + 运营思路）。
2. **T-0 紧接着**：`npm run seo:push -- --all`，把新 URL 分钟级送进百度/必应。
3. **T-0 当天**：同步发小红书/抖音/贴吧（见《小红书发布包》《推广文案》），标题带上版本词。
4. **T+1~3 监测**：百度搜索「金铲铲 S18 攻略 站点:yilangames.com」看是否收录与排名，未收录再推一次。

目标：做**第一批**被收录的 S18 攻略源，吃版本初期的搜索红利。

## 6. 配额与注意

- **⚠️ 新站配额为 0 的解法（关键）**：百度对**未填备案号**的新站，sitemap 提交 / 手动提交 / 主动推送配额**统统为 0**（页面显示「今日提交上限：0 条」）。到「普通收录」页点 **「填写站点的主体备案号」**，填入 ICP 备案号（yilangames.com = `苏ICP备2026066445号`，即 footer 里 `苏ICP备2026066445号-1` 的主体部分）。百度对接工信部备案库核对通过后，**每日提交上限与主动推送配额都会提升**。这是新站从 0 → 有配额的前提。
- 百度每日配额有限，**优先推新/更新页**，不要无脑全量刷（会浪费配额、甚至被降权）。
- 重复推送已收录 URL 无害（搜索引擎去重）。
- 推送成功 ≠ 一定收录，内容质量仍是根本；推送只是「插队提醒」。
- 配合《百度资源平台提交指南》完成站点验证 + sitemap 提交，双管齐下。

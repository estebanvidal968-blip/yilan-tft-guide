采购资源（均在云厂商官网） 待你执行

  • 买域名：腾讯云 / 阿里云，.com 或 .cn，约 ¥50–80/年（.cn 需实名）
  • 租国内服务器：腾讯轻量应用服务器 / 阿里 ECS，约 ¥60/年起（选「中国大陆」地域）
  • 决定：必须国内节点，否则无法备案
账号需本人实名（个人身份证）。企业可走企业实名，备案更顺。
2

ICP 备案（国内发布硬门槛） 待你执行

  • 在服务器提供商控制台提交备案（腾讯云 / 阿里云代提交至管局）
  • 实名 + 人脸 / 短信核验 + 填写网站信息
  • 管局审核 1–2 周
  • 通过后获备案号（如 京ICP备XXXX号），需悬挂在网站底部
决策点：备案是否通过？
否 → 按管局退回意见补材料重提 是 → 进入部署阶段 ✅
3

部署上线 待你 / 我执行

  • git push 到 GitHub
  • VPS 上 Docker 部署（已有 Dockerfile）：docker build + docker run -v 数据卷 -p 3000
  • nginx / Caddy 反代 + HTTPS 免费证书
  • 进程守护：systemd 单元 或 pm2，开机自启
  • 域名 DNS 解析（A 记录）指向服务器公网 IP
  • 验证：备案号悬挂 + HTTPS 可达 + 点赞/评论持久
存储层：VPS 单实例 + 挂卷 → 现有 JSON 点赞/评论可用；若未来多实例需迁 SQLite/Postgres（改动 lib/socialStore.js）。

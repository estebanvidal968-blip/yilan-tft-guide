# 百度搜索资源平台提交指南（yilangames.com）

目标：让百度收录你的站点，用户搜「金铲铲之战 S18 攻略 / 阵容码 / 自然仙灵」时能找到弈览。

前置条件（均已满足）：
- ✅ 域名 `yilangames.com` 已实名、ICP 备案已通过
- ✅ HTTPS 已上线（`https://yilangames.com` 返回 200）
- ✅ `/sitemap.xml` 已生成（含 28 篇攻略 + 阵容/装备/羁绊/弈子/符文等全部 URL）
- ✅ `/robots.txt` 已允许抓取并指向 sitemap

---

## 一、注册并添加站点

1. 打开 https://ziyuan.baidu.com （百度搜索资源平台），用**百度账号**登录；没有就先注册一个。
2. 左侧「站点管理」→ **添加网站** → 输入 `yilangames.com`（不带 https://）。
3. 站点类型选「**PC 站 / 自适应**」（站点本身是响应式，选自适应最省事）。

## 二、验证站点归属（三选一，推荐文件验证）

| 方式 | 操作 | 适合 |
|------|------|------|
| 文件验证（推荐） | 平台给一个 `baidu_verify_xxx.html`，放到站点根目录公网可访问（部署后 `/baidu_verify_xxx.html` 能打开），点验证 | 最稳，无需动 DNS |
| HTML 标签验证 | 把给定 `<meta>` 加到首页 `<head>` 顶部，重新部署后验证 | 不想动文件时 |
| CNAME 验证 | 在 DNSPod 给域名加一条 CNAME 记录（平台给的主机名） | 熟悉 DNS 时 |

> ⚠️ 文件验证：把下载的 html 放到项目 `public/` 目录再部署，公网 `https://yilangames.com/baidu_verify_xxx.html` 能打开即算验证通过。

验证通过后，平台会显示「验证成功」，站点进入「正常」状态。

## 三、提交 sitemap（核心一步）

1. 左侧「**普通收录**」→ 「sitemap」→ **提交**。
2. 填写：`https://yilangames.com/sitemap.xml` → 提交。
3. 提交后看「sitemap 列表」里的「状态 / 已抓取 / 已索引」数量，通常几小时到几天内开始抓取。

## 四、开「快速收录」（更快进索引）

1. 左侧「**快速收录**」→ 申请开通（需站点原创度达标，攻略站一般没问题）。
2. 开通后可用 **API 主动推送**新 URL，百度优先抓取。

主动推送示例（把待收录 URL 一行一个写进 `urls.txt`，再执行）：
```bash
curl -X POST "http://data.zz.baidu.com/urls?site=yilangames.com&token=你的TOKEN" \
  -H 'Content-Type: text/plain' \
  --data-binary @urls.txt
```
> `TOKEN` 在「普通收录 → 接口调用」页获取。`urls.txt` 示例：
> ```
> https://yilangames.com/guides/s18-fairy-refresh
> https://yilangames.com/guides/s18-econ-timing
> ```

## 五、日常监控

- 「**数据监控**」看索引量、抓取频次、异常。
- 「**抓取诊断**」可手动提交某条 URL 让百度立刻抓取（发新攻略后用）。
- 「**搜索关键词**」看用户实际搜什么词进来的，反推该补哪些长尾攻略。

## 六、其它搜索引擎（同理，顺手做）

- **必应**（国际 + 国内）：https://www.bing.com/webmasters → 添加站点 → 提交 `https://yilangames.com/sitemap.xml`
- **360 搜索**：https://zhanzhang.so.com → 提交 sitemap
- **搜狗**：https://zhanzhang.sogou.com → 提交 sitemap

## 七、注意事项

- 攻略内容是原创撰写，收录友好；**不要**在别处全文搬运本站内容（会被判重复、降权）。
- 新攻略发布后，跑一次上面「四」的主动推送，加速收录。
- 公安联网备案（30 日内）记得补，合规也影响用户信任。
- 百度收录见效周期：新站通常 1–4 周，期间保持内容更新即可。

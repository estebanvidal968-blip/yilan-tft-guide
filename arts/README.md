## 这是什么

金铲铲之战「画之灵」赛季的攻略板块。画之灵是**国风赛季**（原赛季 2024-03-28 随 4.6 版本上线），
**2026-09-29 于 18.3 版本限时返场**，返场加入全新「绘境」机制与「狂风/发财奇遇」。

与站内现有内容的区别：
- 现有 `/`、`/guides`、`/comp` → S18 自然之力
- `/legends` → 英雄联盟传奇 · 海克斯典籍
- **`/arts` → 画之灵（本板块）**

## 目录结构

```
arts/                       ← 板块独立目录（内容与样式都在这里，不混进主站）
├── README.md               ← 本文件
├── arts.css                ← 板块样式（作用域限定 .ar，不污染主站）
└── data/
    ├── mechanics.js        ← 赛季概览 + 绘境格 + 奇遇系统 + 运营节奏
    ├── traits.js           ← 羁绊（20 个，按经济/输出/前排/功能四类分组）
    └── comps.js            ← 阵容推荐（10 套）

app/arts/                   ← 站点路由（**单页版**）
├── layout.js               ← 板块布局（引入样式 + 上线开关）
└── page.js                 ← 唯一页面，页内锚点分六段：
                              赛季概览 / 绘境机制 / 奇遇系统 / 运营节奏 / 羁绊全览 / 阵容推荐
```

## ⚠️ 上线前需要确认的点

1. **阵容部分来源较弱**：10 套阵容整理自返场后公开的社区攻略（T0 盘点），
   属社区口径，**没有像 S18 那样的官方数据接口可校验**（画之灵无对应真源表）。
   建议：逐套在游戏内确认羁绊可组，或以实际对局表现修正强度分档。
2. **返场版本的羁绊调整细节**：官方公告已说明「吉星重做、山海绘卷/灵魂莲华新增棱彩、幽魂重做」，
   但具体数值未完全公开。当前显示的是原版数值 + 调整说明，**上线前建议以游戏内描述校对**。
3. **绘境格数值**：7 种格子的效果描述来自官方公告与合作媒体前瞻，数值可能随版本微调。
4. 弈子费用与羁绊归属来自官方玩法概览，返场若调整了费用需同步。
